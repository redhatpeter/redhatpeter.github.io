## Building applications with foundation models

*AI Engineering* by Chip Huyen explores how to build applications using existing foundation models, rather than starting by training a model from scratch.

The book connects model selection and adaptation with evaluation and deployment. It examines how developers can move from a simple approach toward more sophisticated techniques while assessing whether those changes actually improve the application.

### Topics to explore

- How AI engineering differs from traditional machine learning engineering.
- Evaluating open-ended model outputs, including approaches that use AI as a judge.
- Prompt engineering, retrieval-augmented generation (RAG), fine-tuning, and agents.
- Choosing models, datasets, benchmarks, and metrics for an application's needs.
- Managing latency and cost when serving foundation models.

### A companion to Designing Machine Learning Systems

This book complements Chip Huyen's [Designing Machine Learning Systems]({{ '/favorite-reads/designing-machine-learning-systems/' | relative_url }}). That book takes a broader view of production ML systems, while *AI Engineering* focuses on applications built with foundation models.
